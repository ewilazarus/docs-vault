## Docs vault

`docs/` is an Obsidian vault kept by the `docs-vault:vault-keeper` agent. Never read or
write it yourself: send the keeper a request, in the format the `docs-vault:keeper-contract`
skill describes.

- **Ask it** before work the vault documents, or to answer how or why something is the way
  it is. Wait for the answer.
- **Have it record** work in the background once you changed something outside the repo,
  made a choice whose reason matters later, left work unfinished, finished a follow-up, or
  found a note wrong. Routine code changes that git explains need no record.
